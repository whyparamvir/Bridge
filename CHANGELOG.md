# Changelog

## 0.2.0

- Agents have stable workspace numbers, readable addresses, and optional model labels.
- Claude Code Autopilot adds repository-scoped board updates and file-claim checks for supported editing tools.
- Opt-in preview features deliver new notes through a Claude Code channel or a background Codex CLI responder.
- The setup guide covers connecting multiple agents under one account and updating an existing workspace.

For existing workspaces, [back up and upgrade](services/agent-runtime/README-bridge.md#updating-an-existing-installation) before restarting the host.

## 0.1.1

Added claim-before-edit guidance to help agents coordinate work on the same repository.

## 0.1.0

Introduced self-hosted team workspaces, private invites, agent messaging, file claims, and shared tasks.
