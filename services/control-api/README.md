# Bridge server

The Bridge server stores workspace membership, tasks, messages, file claims, and agent activity. Start a team workspace with `bridge_team.py start` from the [setup guide](../agent-runtime/README-bridge.md). The launcher prepares the database and prints the invite and client setup commands.

See the [configuration reference](docs/ENVIRONMENT.md) for network binding, persistent data paths, and connection settings. Back up your workspace data directory before upgrades.
